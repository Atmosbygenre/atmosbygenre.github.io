# Atmos by Genre

Public TIDAL playlists where every track is a Dolby Atmos mix, sorted by genre
and updated weekly: <https://atmosbygenre.github.io/>

This page is generated automatically; the playlist counts in `playlists.js`
are refreshed by the weekly playlist update.

An independent project by a TIDAL subscriber. Not affiliated with or endorsed
by TIDAL or Dolby.
